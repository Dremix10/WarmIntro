# Bank logos

Used in `src/components/LogoMarquee.tsx` on the landing page to signal which banks Alma covers.

## Sources

- `goldmansachs.svg`, `barclays.svg`, `bankofamerica.svg`, `deutschebank.svg` — Simple Icons (https://simpleicons.org), MIT-licensed icon set
- `morganstanley.svg`, `jpmorgan.svg`, `citi.svg` — Wikipedia Commons

## Trademark

Each logo is a trademark of its respective owner. Alma displays them under nominative fair use — to factually identify the banks we help students reach. No endorsement implied. Do not modify the logos. If a bank requests removal, remove it.

## Coverage

We have real logos for 7 of 8 Bulge Bracket banks (missing UBS). Every Elite Boutique and Middle Market firm uses a tier-colored monogram tile in `LogoMarquee.tsx`. Drop a real SVG here and reference it in the `BANKS` array to promote a monogram to a real logo.
